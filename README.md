## 概要
iPhoneで快適に使える、シンプルで高機能なToDo Webアプリです。
PWA対応、IndexedDBによる完全ローカル保存、JSONエクスポート/インポート機能を備えています。
別端末との自動同期は標準で行いません（データは端末内にのみ保存されます）。

## 主な機能
- タスク管理（作成、編集、削除、完了・未完了）
- 期限設定（絶対日付、相対日付対応。月末処理対応済）
- 繰り返しタスク
- サブタスク管理
- カレンダー表示
- 統計情報
- ダークモード/ライトモード対応
- データマイグレーションとバックアップ・復元

## GitHub Pagesへの公開手順
1. このプロジェクトの全ファイルをGitHubの新しいリポジトリにプッシュします。
2. リポジトリの `Settings` -> `Pages` に移動します。
3. `Source` を `Deploy from a branch` に設定し、ブランチを `main` (または `master`) の `/root` に指定して `Save` を押します。
4. 数分待つと公開URLが生成され、アクセス可能になります。
